# Assets & Hardware Specifications

This directory organizes hardware datasheets, 3D CAD models, and technical schematics for the **DCC Printer** Device Art capstone project.

To keep the repository clean and ensure fast, reliable rendering on GitHub:
- **No duplicate binary data is stored here.**
- All items link directly to their source files in the root [`dcc-printer`](../README.md) repository.

---

## Directory Navigation

- **[datasheets/](datasheets/README.md)**: Technical PDF datasheets for the Cashino thermal printer, LCD1602 module, DS3231 RTC, Alpha rotary switch, and control knob.
- **[models/](models/README.md)**: 3D STEP AP214 models for the LCD1602 screen, PCF8574 I2C backpack, and DS3231 RTC board.
- **[images/](images/README.md)**: High-resolution component photography and circuit schematics.
