# Pointer Control Knob Datasheet

The technical dimensional drawing for the 15mm knurled aluminum pointer control knob is located in the root repository.

- **Direct GitHub PDF Link:** [knob.pdf](../../../knob.pdf)
- **Key Specifications:**
  - Diameter: 15.0 mm knurled aluminum body
  - Bore: Push-fit for 6.0mm knurled potentiometer / rotary switch shafts
  - Indicator: High-contrast white position pointer mark
