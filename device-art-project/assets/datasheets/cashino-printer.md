# Cashino CSN-A2 Thermal Printer Datasheet

The primary PDF datasheet for the Cashino CSN-A2 58mm panel-mount thermal printer is located in the root repository to avoid duplicate binary data.

- **Direct GitHub PDF Link:** [cashino-printer.pdf](../../../cashino-printer.pdf)
- **Key Specifications:**
  - Print Width: 48mm (384 dots/line)
  - Character Width: 32 columns (Font A 12x24)
  - Voltage: 5V–9V DC (Peak current 1.8A–2.2A)
  - Interface: TTL UART (9600 Baud, 8N1)
  - Panel Cutout: $103.0 \times 57.0\text{ mm}$ (Bezel $111.0 \times 65.0\text{ mm}$)
