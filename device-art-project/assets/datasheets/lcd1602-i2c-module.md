# LCD1602 + PCF8574 I2C Display Module Technical Datasheet

The publication-grade 2-page vector datasheet and multi-view dimensional drawing for the LCD1602 Character Display with PCF8574 I2C Backpack is located in the root repository.

- **Direct GitHub PDF Link:** [lcd1602-i2c-module.pdf](../../../lcd1602-i2c-module.pdf)
- **HTML Vector Source:** [lcd1602-datasheet.html](../../../lcd1602-datasheet.html)
- **Key Specifications:**
  - PCB Dimensions: $80.0 \times 36.0\text{ mm}$ (Mounting Pitch $75.0 \times 31.0\text{ mm}$, $4\times \varnothing 3.0\text{ mm}$)
  - Viewing Window: $64.5 \times 16.0\text{ mm}$ (Active Matrix $56.2 \times 11.5\text{ mm}$)
  - Interface: 4-wire I2C (`GND`, `VCC`, `SDA`, `SCL`) at default address `0x27` (or `0x3F`)
  - Header Geometry: Right-angle bent headers allow a slim $14.5\text{ mm}$ total depth vs. $24.0\text{ mm}$ straight headers
